# Campaign Directory

This directory contains all the content for your GURPS campaign.

## Maintenance Instructions

### `.keep` Files
Some directories in this project contain a file named `.keep`. 

> [!IMPORTANT]
> **DO NOT DELETE `.keep` FILES.**
> These files are used to ensure that Git tracks these directories even when they are empty. If you remove them, Git may stop tracking the empty folders, which can break the project structure for other users or in automated environments.
