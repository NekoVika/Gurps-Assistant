# 0010 — The skill editor: final level typed, book decides, GM confirms

**Date:** 2026-10-07 · **Status:** Accepted · **Commits:** 178a8cd

## Decision (settled with the GM)
- The GM types a skill's **final level**, the number rolled against. The editor
  shows what it means: `Average (B222) · DX-1 · 1 pts`.
- The **book decides** a skill's attribute and difficulty. The GM may override
  the attribute and is shown the book's.
- **Points follow the level while they are the book's figure.** A figure the GM
  typed is kept, with the book's beside it.
- When an attribute changes, the editor **offers** to move the skills based on
  it (B170). It never moves them itself.
- A line nothing can read is **reported, never repaired**. The GM: "we can't fix
  anything thrown to us."
- A skill the book does not list is the **GM's own**: they choose its attribute
  and difficulty, and the Skill Cost Table (B170) prices it.
- Attributes are priced the same way (B16-19); changing one never rewrites
  another's line.
