# Decisions

One record per decision the GM and the project have settled. Each says what was
decided, why, and what it rules out, so a later session does not reopen it by
accident. Records are never rewritten: to change a decision, write a new record
that supersedes the old one and mark the old one *Superseded by NNNN*.
