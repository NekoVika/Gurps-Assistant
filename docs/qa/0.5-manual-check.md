# 0.5 — manual check

Covers commits `acf6523` … `feb918e` on `develop`. About 30 minutes; steps 4,
5, 7 and 8 each make one Gemini call.

## 0. Before you start

1. **Back up the campaign.** Copy `AnomalyHuntersCampaign/` to
   `AnomalyHuntersCampaign.qa-<date>/`. Steps 4, 7 and 8 write files.
2. Start the app from the repo root: `.\dev.cmd`. It runs the backend with
   auto-reload and the frontend, and opens the browser.
3. If the app ever seems to ignore a code change, stop with Ctrl+C and run
   `.\dev.cmd` again. The Vite file watcher missed edits several times during
   0.5 work.

## 4. Create Entity — the model chooses, the app prices

Characters → **+ Create** → NPC. Give it a test name, a concept, a short
description that implies **an employer** (that should become a Patron), a
**Per-based skill** (Observation, Search) and **Bad Temper**. Set a target
points value. Run AI Workflow.

- [ ] The success message names the file and says how many lines are **left
      for you to settle**.
- [ ] Attributes: all ten, ST to Basic Move. Ones the model left at default
      are **[0]**.
- [ ] Skills are written `Name/TL8 (Spec) (ATTR/Diff)-Level [pts]`. Per skills
      show `(Per/A)` and are priced.
- [ ] Any skill on a different attribute than the model said, such as Scuba,
      shows the **book's** attribute: `Scuba/TL8 (IQ/A)`.
- [ ] Bad Temper shows its self-control number: `Bad Temper (9) [-15]` or
      similar.
- [ ] Anything the app could not price is still on the sheet, with
      *not priced: reason* and **no** `[cost]`. The points badge says the total
      is a floor.
- [ ] **Edit → GM Summary** has **Left to the GM:** with the Patron/Duty in
      plain words.
- [ ] Gear is a clean table, with weights and costs in the right columns.

## 5. Chat — a drafted change is priced before you see it

Open the character from step 4 (or Test Rook). In chat, ask something like:
*"Update <name> with draft_file: give her Combat Reflexes, raise <a skill she
has> by one level, and add Climbing at DX."*

If Gemini says it is *overloaded*, switch the chat's model to **Gemini 2.5
Flash** and press Retry.

- [ ] The review panel opens with a banner: **"N lines priced by the app."**
- [ ] The diff shows the raised skill **replaced in place** (- old line,
      + new line), not a second copy.
- [ ] Combat Reflexes appears as `Combat Reflexes [15]`. Climbing is priced
      against her DX.
- [ ] **pointTotal is not in the diff.** Your stated total is never changed by
      a draft.
- [ ] Untick one hunk, then Apply. Only the ticked changes land.

Optional — the warning path. Ask: *"Add Fearlessness [4] to <name> directly in
the advantages list."* If the model writes the line itself, the banner should
turn amber and list it as **priced by the model, not the app**.
