# 0.5 — Full Rules Ahead

**Status:** in development on `develop` · **Last release:** v0.4.0 · **Version in `web/package.json`:** still 0.4.0

## Goal

Move the GURPS rules into the app. Of the campaign's sheets that state a point
total, none added up to its own brackets (median error 34%). The answer is not
a better prompt but a split of jobs: **the model chooses, the app prices**
([0001](../decisions/0001-model-chooses-app-prices.md)). The app advises and
never blocks ([0002](../decisions/0002-rules-are-advisory.md)), and every file
is correct when written ([0005](../decisions/0005-correct-when-written.md)).

What shipped is described for the GM in [`CHANGELOG.md`](../../CHANGELOG.md).
The decisions behind it are in [`decisions/`](../decisions/).

## Next — agreed with the GM, in order

1. **Improving a skill from a default** (B173): a skill bought up from another
   skill's default pays only the difference. The catalogue already stores every
   skill's defaults.
2. **Optional specialties** (B169): learned as if one level easier.
3. Small: price `Perk (…)` at 1 point (B100-101); split an unpriced line into

## Known issues

- **The Vite file watcher misses edits** on the development machine: the dev
  server has served stale modules several times during 0.5, once crashing the
  System Rules editor. Restart `dev.cmd`, or check what is served with
  `curl localhost:5173/src/<file>`.
