# Legacy Notes & Catch-Up Folder

Put your old, messy campaign notes, Lore docs, spreadsheets, or PDFs in this folder! 

When you are ready to import them into the standard AI hierarchy, run the `/catch_up` workflow. The AI will read everything placed in this directory and systematically organize it into the main project. 

*Note: The rest of the AI workflows and personas are explicitly instructed to ignore this directory to prevent confusion. This folder is ONLY meant for ingesting legacy data during the catch-up process.*
